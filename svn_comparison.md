# Сравнение Git и SVN

## 1. Почему в Git ветвление «дешёвое», а в SVN — «дорогое»?

В Git ветки создаются быстро внутри локального репозитория и почти не требуют дополнительных ресурсов.

В SVN ветвление связано с копированием директорий на центральном сервере, поэтому этот процесс работает медленнее.

## 2. Можно ли в SVN сделать коммит без интернета? Почему?

Нет. SVN — централизованная система контроля версий. Для создания коммита необходимо подключение к центральному серверу.

Без интернета можно изменять файлы локально, но отправить коммит на сервер нельзя.

## 3. В каких сценариях SVN до сих пор может быть предпочтительнее Git?

SVN может использоваться в старых проектах, которые уже изначально построены на этой системе.

Например, SVN до сих пор встречается в legacy-проектах, в том числе в государственных организациях и банках. В таких случаях переход на Git может не выполняться, поэтому требуется поддерживать существующую систему.
